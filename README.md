# StreetFighter-DQN 🥊

一个基于 **Deep Q-Network (DQN)** 的街头霸王 II (Street Fighter II) 强化学习实验项目。本项目旨在通过经典游戏环境验证强化学习算法的有效性，并探索多进程加速训练的实现。

## 🌟 技术亮点

* **核心算法**：采用经典 **DQN** 架构，引入 **Target Network（目标网络）** 与 **Soft Update（软更新）** 技术，显著提升了 Loss 的稳定性。
* **高效训练**：利用 `Worker + SharedMemory` 架构实现多环境并行数据采集，突破单进程训练的数据瓶颈。
* **工程实践**：参考《深度学习入门》（鱼书）系列技术栈，纯手工实现环境封装与网络调优。

## 🛠️ 环境要求

在开始前，请确保你的开发环境已配置以下依赖：

* `torch` (PyTorch 深度学习框架)
* `stable-retro` (用于集成经典游戏 ROM)
* `gymnasium` (环境接口)
* `numpy` (数值计算)

## 🚀 快速开始

### 1. 导入 ROM

由于版权限制，本项目不提供游戏 ROM。请准备符合 **SHA-1** 校验要求的《街霸 2》ROM 文件：

1. 将 ROM 改名为 `rom.md`。
2. 放入 `stable-retro` 指定的库目录中（具体路径参考库内校验文件提示）。

### 2. 开启训练

```bash
python main.py

```

### 3. 模型测试

使用训练好的权重进行推理演示：

```bash
# 测试最新迭代的模型
python model_test.py --reward

# 测试特定次数的模型并输出推理向量
python model_test.py --it 500 --vec --reward

```

* `--it N`: 指定第 N 次迭代的权重。
* `--vec`: 输出推理向量（用于监测网络是否塌陷/输出单一化）。
* `--reward`: 实时显示奖励数值。
